# 各平台发布文案矩阵（SEO 关键词按平台人群定制）

> 使用原则：标题=高频搜索词前置；描述=人群痛点词+平台词+能力词；标签=平台搜索框会联想的词。
> 共同基线：不暴露佣金/联盟性质（平台红线），话术=「返现/省钱/比价」。最后更新 2026-10-13。

---

## 1. 扣子 Coze（字节；开发者+企业用户；搜索词偏「插件/工具/MCP/电商」）

**插件名**：全网比价购物助手（淘宝/京东/拼多多）
**描述**：
> 接入 5 万+ 精选商品的电商购物 MCP：自然语言搜商品（支持预算和「要便宜/要正品」偏好）、
> 多商品对比矩阵、优惠券与到手价查询、淘宝/京东/拼多多官方渠道购买链接。
> 适合做 AI 导购、电商客服、比价机器人、带货助手的插件底座。
**标签**：电商、购物、比价、MCP、商品搜索、导购、淘宝、京东、拼多多、AI买手
**人群关键词逻辑**：扣子用户搜「电商」「带货」「客服机器人」——把「导购/客服/带货底座」放前面。

## 2. DeepSeek Harness / DSH Market（开发者；偏「server/工具链」）

**Name**: Yuantoutao Shopping (源头淘购物)
**Description**:
> Shopping MCP server for Chinese e-commerce: 50k+ curated products across Taobao/JD/
> Pinduoduo, explainable 3-factor ranking (score + reasons per item), coupon-aware
> comparison matrix, affiliate buy links with automatic attribution, order tracking.
**Tags**: shopping, e-commerce, taobao, jd, pinduoduo, mcp-server, commerce, price-comparison
**人群逻辑**：DSH 用户搜「server」「tools」英文词——英文描述为主，中文站名保留。

## 3. 智谱清言 / bigmodel 智能体（普通用户+开发者；搜索词偏「返利/省钱/比价」）

**智能体名**：AI 网购省钱助手（淘宝京东拼多多比价返现）
**简介**：
> 买东西前先问它：一句话搜全网好价，三平台比价、查历史价格防假促销、领券下单返现金。
> 支持「500 元内送女朋友的礼物」这类自然语言，直接给可购买链接。
**开场白**：想买什么？告诉我预算，我帮你全网找最低价～
**标签**：网购、省钱、比价、返现、优惠券、好价
**人群逻辑**：清言用户搜「省钱」「返现」「比价」——价格敏感词全放。
